# Decisions log

Choices made for this repository, newest at the bottom of the table. The plan for the current work is [plan-revision.md](plan-revision.md).

The log is append-only: a changed decision gets a new row that names the row it replaces, and old rows are never edited, so two branches adding rows merge cleanly (`merge=union` in `.gitattributes`). Search it rather than reading it whole, by area or by word: `grep -n -E '^\| [0-9-]+ \| [^|]*Agents' docs/decisions.md`. Past about 300 lines, replaced rows and rows for finished work move to `decisions-archive-<year>.md`, in a commit of their own.
